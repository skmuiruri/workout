Push · Pull · Legs

How to train this program
  • Rest 60–90 seconds between sets.
  • Superset pairs: do one set of each back to back, then rest.
  • Stop each set 1–2 reps short of failure.
  • When every set reaches the top of the rep range, add weight next session. A green “Add weight” tag shows when you're there.
  • Every 6–8 weeks, take a lighter week with about half the sets.
