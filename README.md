# Six-Day PPL Log

A phone-friendly push/pull/legs workout page with exercise photos and a simple weight log.
Logs are saved in your phone's browser (localStorage), so they stay on that device only.

## Publish on GitHub Pages

1. Create a new repository on GitHub, for example `workout`.
2. Upload everything in this folder (`index.html`, `manifest.webmanifest`, the icons and the `img/` folder) to the root of the `main` branch.
3. In the repo, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, pick `main` and `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/workout/`.

## Put it on your home screen

- **iPhone (Safari):** Share → Add to Home Screen.
- **Android (Chrome):** ⋮ menu → Add to Home screen / Install app.

Opening it from the home-screen icon keeps using the same saved log. Opening it in a different browser starts a fresh log.
