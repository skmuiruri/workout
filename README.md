# Six-Day PPL Log

A phone-friendly push/pull/legs workout page with exercise photos and a simple weight log.
Logs are saved in your phone's browser (localStorage), so they stay on that device only.

## Publish on GitHub Pages

1. Create a new repository on GitHub, for example `workout`.
2. Upload everything in this folder (`index.html`, `manifest.webmanifest`, the icons and the `img/` folder) to the root of the `main` branch.
3. In the repo, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, pick `main` and `/ (root)`, and save.
4. After a minute the site is live at `https://<your-username>.github.io/workout/`.

## Put it on your home screen

The site is live at <https://skmuiruri.github.io/workout/>.

### iPhone (Safari)

1. Open **Safari** (it must be Safari, not Chrome) and go to the link above.
2. Tap the **Share** button (the square with an arrow pointing up at the bottom of the screen).
3. Scroll down the share sheet and tap **Add to Home Screen**.
4. The name shows as **PPL Log**. Change it if you like, then tap **Add**.

An icon appears on your Home Screen. Opening it launches the app full screen without the Safari address bar.

### Android (Chrome)

1. Open Chrome and go to the link above.
2. Tap the **⋮** menu and choose **Add to Home screen** or **Install app**.

### Good to know

- **Your log is tied to the icon.** Weights saved from the home-screen app live in that app's own browser storage. Opening the site in a different browser shows a separate, empty log.
- **Updates arrive automatically.** Changes pushed to GitHub appear on the next launch. If you see a stale version, close the app fully and reopen it.
